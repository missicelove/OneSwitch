# 明天（9/30）真机测试清单

两台 Mac 都已是 v1.0.4。解锁后按顺序测，每项 1–3 分钟。

## 1. 键鼠共享（最重要，昨晚已修复“划不过去”）
- 确认 Deskflow 已退出。
- 在 Mac Studio 上把鼠标一直往**左**推（设置里 MBP 在左侧）→ 光标应出现在 MBP 屏幕右边缘。
- 在 MBP 上移动、点击、滚动、拖动窗口；打字（中英文输入法都试一下）；试 ⌘C / ⌘V、音量键。
- 把鼠标往右推回 Studio → 光标回到 Studio 左边缘。
- 在 MBP 上按 ⌃⌥⌘ 空格 → 立即切回 Studio。
- 在 Studio 复制一段文字，切到 MBP 粘贴（剪贴板同步）。
- 反馈：延迟感、有没有卡键、Studio 的光标在控制 MBP 时是否隐藏。

## 2. 菜单栏图标（已改为 Hidden Bar 同款系统原生隐藏）
- 两台 Mac：菜单栏应只有 OneSwitch 的「<」，**没有「«」和空白**。
- 点「<」→ 所有图标出现，按钮变「>」；10 秒后自动隐藏（鼠标停在菜单栏时会等）。
- MBP：「<」应在右侧系统图标旁，不会被收走。
- 设置 → 菜单栏图标 → 要隐藏的 App：每个 App 可选 自动 / 始终隐藏 / 始终显示。
- 注意：隐藏以 App 为单位；时钟、Wi‑Fi、控制中心等系统图标始终显示。

## 3. 系统监控 / 防止锁屏 / 文件同步（顺手看一眼）
- Studio 上 CPU/内存/网络 各自一个图标；MBP 上合并成一个。点开有详情面板。
- 防止锁屏：工作日 08:00–19:00 自动开启（按波兰节假日）。
- 文件同步：测试文件夹 `~/OneSwitch-SyncTest`（含一个 2 GB 文件），确认后可在设置里移除并删除。
