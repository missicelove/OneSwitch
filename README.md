# OneSwitch

OneSwitch 是一个常驻菜单栏的 macOS 小工具，平时没有 Dock 图标（打开设置窗口时才会出现在 Dock 和 ⌘Tab 里）。它主要服务于两台用雷雳 4 线直连的 Mac（例如 Mac Studio 和 MacBook Pro），共有六项功能：

| 功能 | 作用 |
| --- | --- |
| **防止锁屏** | 让屏幕常亮、不进屏保也不自动锁屏。可以手动开启一段时间（5 分钟到 12 小时，或无限期），也可以按“自动计划”在工作日的固定时段开启（默认 08:00–19:00），计划会参考节假日日历（按系统时区自动选择：中国大陆含调休 / 波兰 / 不使用）。开启时主图标会换成你选的图标（默认闪电）。 |
| **菜单栏图标** | 整理菜单栏图标，效果和 Hidden Bar 一样：菜单栏上只有一个「<」。macOS 27 上使用系统原生隐藏（不会出现「«」和空白）；每个 App 可设为 自动（在「<」左侧即隐藏）/ 始终隐藏 / 始终显示。点「<」显示隐藏的图标，5–60 秒后自动收起；刘海屏放不下时只显示放得下的，其余可用“显示全部图标”或 ⌥ 点击「<」。 |
| **系统监控** | 在菜单栏显示 CPU、GPU（含 GPU 占用的内存）、内存、网络、磁盘、功率、温度，可单项或合并显示。点击任一图标弹出详情面板，里面有历史曲线和占用最高的进程。 |
| **雷雳互联** | 通过雷雳网桥连接另一台 Mac（Bonjour 自动发现，连接用配对码加密），同时负责给雷雳网桥配置静态 IP（10.77.0.1 ⇄ 10.77.0.2）。文件同步和键鼠共享都依赖它。 |
| **文件同步** | 两台 Mac 之间实时双向同步文件夹，做法类似 Syncthing。能处理冲突，被覆盖或删除的文件可以按设置保留旧版本。 |
| **键鼠共享** | 两台 Mac 共用一套键盘鼠标，做法类似 Deskflow / Universal Control。鼠标移过屏幕边缘就切换到另一台 Mac（也可按 ⌃⌥⌘ 空格），切换时剪贴板双向同步（含图片）。鼠标滚轮在另一台 Mac 上按你选的方向（默认与 Windows 一致）平滑滚动，可与 Mos 共存。 |

所有功能都能在菜单栏的 OneSwitch 图标里操作，详细设置在“设置…”窗口中。

---

## 1. 系统要求

- Apple 芯片的 Mac，macOS 14 或更高（开发和测试环境是 macOS 27）。
- 构建时只需要“命令行工具”（Swift 6），不用装 Xcode。没装过的话先执行：`xcode-select --install`。
- 两台 Mac 用雷雳 4 / 雷雳 3 线直连（系统会自动生成“雷雳网桥”，设备名 `bridge0`）。

## 2. 安装

一般的做法是：在 **Mac Studio**（下文叫“构建机”）上构建并安装，再用脚本把同一个构建推送到 **MacBook Pro**。两台 Mac 运行同一个签名的构建，各自授予过的系统权限在以后更新时都会保留。

### 2.1 创建固定签名（只需一次，在构建机上）

```sh
cd ~/OneSwitch
./scripts/setup-signing.sh
```

这一步会在 `~/Library/Application Support/OneSwitch-Signing/` 创建一个私有钥匙串，里面放自签名证书“OneSwitch Local Signing”。登录钥匙串不会被改动。

为什么要这一步：macOS 按签名识别 App。如果每次构建都换签名（ad-hoc 签名），更新后“辅助功能”“输入监控”等权限就会失效，需要重新授权。用了固定签名，权限会一直有效。

> 重复运行这个脚本是安全的。如果想重建证书，先删除上面那个目录再运行（导入过开发者 ID 的话，它的私钥也在这个目录里，会一起被删掉）。换了新证书以后，两台 Mac 都需要重新授权一次。

### 2.2 在本机构建并安装

```sh
./scripts/install.sh
```

这个脚本依次做四件事：构建 release 版本、签名（`scripts/build-app.sh`），退出正在运行的旧版 OneSwitch，把新版装到 `/Applications/OneSwitch.app`，然后启动它。以后每次更新都重新运行这一条。

只想构建、不想安装的话，运行 `./scripts/build-app.sh`，产物在 `build/OneSwitch.app`。

### 2.3 部署到另一台 Mac

另一台 Mac（MacBook Pro）上需要先准备好 SSH，只做一次：

1. 打开“系统设置 → 通用 → 共享 → 远程登录”。
2. 在构建机上生成专用密钥，并把公钥复制到对方（地址可以用对方的雷雳网桥 IP，没配静态 IP 之前是 169.254.x.x）：

   ```sh
   ssh-keygen -t ed25519 -f ~/.ssh/oneswitch_peer -N ""
   ssh-copy-id -i ~/.ssh/oneswitch_peer.pub <对方用户名>@<对方 IP>
   ```

之后每次部署都在构建机上执行（先运行 2.2，确保 `build/OneSwitch.app` 是最新的）：

```sh
./scripts/deploy-peer.sh
```

脚本会按 10.77.0.2 → 10.77.0.1 → 雷雳网桥上的 169.254.x.x 邻居的顺序自动寻找对方（不会连到本机自己的地址）。找到后打包传过去，校验签名，退出对方正在运行的 OneSwitch，安装到对方的 `/Applications`，再启动。

- 手动指定对方：`PEER=<对方用户名>@10.77.0.2 ./scripts/deploy-peer.sh`
- 用户名或密钥不同时：`PEER_USER=<用户名> PEER_KEY=~/.ssh/<密钥> ./scripts/deploy-peer.sh`
- 对方用户名和本机不同时，可以把 `PEER_USER=<用户名>`（以及 `PEER_KEY=…`）写进 `scripts/deploy-peer.local`，以后直接运行即可（这个文件不会提交到 git）。
- 对方 Mac 必须已经登录到桌面，否则程序装好了但无法启动。

### 2.4 使用 Apple 开发者 ID 签名并公证（可选）

加入了 Apple Developer Program 后，可以把上面的自签名换成 Apple 签发的“Developer ID Application”证书。好处：

- 系统按**团队 ID** 识别 OneSwitch，证书续期或换新都不影响已经授予的权限。
- “登录项”里不再显示为“未识别的开发者”。
- 经过 Apple 公证后，把 App 发给别人（下载、隔空投送、邮件）也能直接打开，不会被“无法验证开发者”拦住。

不需要 Xcode，步骤如下（都在构建机上）：

1. 生成私钥和证书签名请求（CSR）。私钥只保存在上面那个私有钥匙串目录里，不会离开这台 Mac：

   ```sh
   ./scripts/setup-developer-id.sh request
   ```

2. 用**账户持有人**身份登录 [developer.apple.com](https://developer.apple.com/account/resources/certificates/list) → Certificates → “+” → **Developer ID Application** → Profile Type 选 **G2 Sub-CA** → 上传第 1 步生成的 CSR（脚本会在访达里显示它）→ 下载证书 `developerID_application.cer`。
3. 导入证书。脚本会核对证书是否和私钥配对、是否由 Apple 根证书签发，下载 Apple 的中间证书，最后试签一次。这张公开的中间证书（不含私钥）也会放一份到登录钥匙串，codesign 要靠它来建立证书链：

   ```sh
   ./scripts/setup-developer-id.sh import ~/Downloads/developerID_application.cer
   ```

4. 重新运行 2.2 和 2.3。之后 `build-app.sh` 会自动用开发者 ID 签名（附带 Apple 的时间戳，签名时需要联网）。**签名换了以后，两台 Mac 都要在“辅助功能”“输入监控”里重新授权一次**，以后就不用再授权了。想临时改回自签名，运行 `LOCAL_SIGNING=1 ./scripts/install.sh`。

要把 App 发给别人时再做公证。先保存一次公证凭据：在 [account.apple.com](https://account.apple.com) → 登录与安全 → App 专用密码 里生成一个密码，然后运行下面的命令，按提示粘贴这个密码（团队 ID 在第 3 步的输出里）：

```sh
xcrun notarytool store-credentials OneSwitch-Notary --apple-id <你的 Apple ID> --team-id <团队 ID>
```

以后每次发布：

```sh
./scripts/build-app.sh && ./scripts/notarize.sh
```

公证一般要 1–5 分钟，完成后得到 `build/OneSwitch-<版本>.zip`，直接发送即可。`./scripts/setup-developer-id.sh status` 可以查看证书有效期和公证凭据是否可用。两台自己的 Mac 之间用 `deploy-peer.sh` 部署时不需要公证。

## 3. 首次运行与权限

第一次启动时，OneSwitch 会打开设置窗口的“通用”页，并自动开启“开机自动启动”。如果系统要求批准，按页面上的“打开“登录项”设置…”按钮去允许。

两台 Mac 都要授予下面这些权限。在“设置 → 通用 → 系统权限”里可以看到当前授权状态，点“授权…”会弹出系统提示或直接打开对应的设置页面：

| 权限 | 位置 | 用途 |
| --- | --- | --- |
| **辅助功能** | 系统设置 → 隐私与安全性 → 辅助功能 | 键鼠共享：服务端控制另一台 Mac 时接管键鼠，客户端模拟键鼠操作。菜单栏图标：读取图标位置、自动整理（macOS 27 上用来把图标完全收起）。 |
| **输入监控** | 系统设置 → 隐私与安全性 → 输入监控 | 键鼠共享服务端读取键盘输入并转发。在本机工作时不会拦截按键。 |
| **本地网络** | 系统设置 → 隐私与安全性 → 本地网络 | 雷雳互联发现并连接另一台 Mac。第一次连接时系统会弹窗询问，请选“允许”。 |
| **管理员密码** | 系统弹出的密码框 | 雷雳互联第一次给雷雳网桥设置静态 IP 时需要输入一次。设置会一直保留，重启后也不用再输。 |
| 通知（可选） | 系统设置 → 通知 → OneSwitch | 防止锁屏的定时结束提醒、文件同步冲突和错误提醒。 |

> 授予“输入监控”后，如果键鼠共享仍提示没有权限，从菜单栏退出 OneSwitch 再重新打开。

## 4. 配对两台 Mac（雷雳互联）

1. 用雷雳线把两台 Mac 连起来。
2. 在其中一台打开“设置 → 雷雳互联”，点 **生成随机配对码**，再点 **拷贝**。
3. 在另一台的同一个页面粘贴，或手动输入**完全相同**的配对码（区分大小写）。
4. 状态变成 **已连接 …（雷雳）** 就说明成功了。菜单里会显示类似 `已连接 我的 MacBook Pro · 雷雳 · 0.4 ms` 的一行。

说明：

- **只有启用了文件同步或键鼠共享，才会建立连接**。两者都关闭时，状态显示“未启用文件同步或键鼠共享”，这是正常的。
- **静态 IP**：“自动配置雷雳网桥静态 IP”默认是开启的。台式机用 10.77.0.1，笔记本用 10.77.0.2，子网掩码 255.255.255.0，**不设路由器**，所以不影响 Wi‑Fi 或以太网上网。第一次会弹出管理员密码框；如果点了取消，之后不会再自动弹出，需要时到本页点 **立即配置**。想恢复原状，点 **恢复为自动（DHCP）**。
- **网络接口**：默认是“优先雷雳网桥”。“仅雷雳网桥”表示拔掉雷雳线后就断开，“任意网络”表示也可以走 Wi‑Fi 或以太网。
- 如果 Bonjour 在 5 秒内没有发现对方，会直接连接“对方 IP”。这一栏留空时，按静态 IP 方案自动推算。端口默认 52525，两台要一致。

## 5. 设置文件同步

1. 两台 Mac 都在“设置 → 文件同步”里打开 **启用文件同步**（默认已开启），并确认上方显示对方已连接。
2. 在一台 Mac 上点 **添加文件夹…**，选择要同步的文件夹。
3. 另一台 Mac 会收到 **共享邀请**（设置页和菜单栏菜单里都有）。点 **接受…**，选择本机上存放的位置（可以是新建的空文件夹，也可以是已有同样内容的文件夹），接受后开始同步。
4. 同步状态、待同步数量、速度、最近活动和冲突文件都能在设置页里看到；菜单中每个文件夹都有“打开文件夹 / 立即扫描 / 暂停同步”。

需要知道的几点：

- 每个同步文件夹的根目录下会有一个 `.oneswitch` 标记目录，**不要删除它**。如果外接磁盘没接上，或者文件夹被移动了，同步会自动停下，不会把“文件不见了”当成删除同步到另一台。确认位置正确后，可以点“重新创建标记…”恢复同步。
- **移除**同步文件夹只是停止同步，两边的文件都不会被删除。
- 两台 Mac 同时改了同一个文件时，较新的修改保留原文件名，另一份另存为 `文件名.sync-conflict-日期-设备名.扩展名`。
- 被对方覆盖或删除的文件怎么处理，可以在“编辑…”里选：不保留 / 移到废纸篓（默认）/ 保存到 `.oneswitch/versions`（保留 30 天）。
- 忽略规则每行一条，例如 `*.log`、`node_modules`、`/build`。`.DS_Store` 等系统文件总是会被忽略。

## 6. 设置键鼠共享

1. 两台 Mac 都在“设置 → 键鼠共享”里打开 **启用键鼠共享**（默认已开启）。
2. **本机角色**：接着键盘鼠标的那台（Mac Studio）设为 **服务端**，另一台（MacBook Pro）设为 **客户端**。默认台式机是服务端、笔记本是客户端，一般不用改。两台设成同一个角色时会提示冲突。
3. 在**服务端**的“屏幕布局”里点方框，选择 MacBook Pro 屏幕所在的方位（默认在右侧）。
4. 按第 3 节授予权限：服务端需要辅助功能和输入监控，客户端需要辅助功能。

使用方法：

- 把鼠标推过服务端屏幕的对应边缘，就切换到另一台 Mac；在那台 Mac 上把鼠标从相对的边缘移回来，就切回本机。
- 快捷键 **⌃⌥⌘ 空格**（可以在设置里修改）可以随时切换或切回。菜单里也有“切换到 …”和“切回本机”。
- 可选项：边缘停留时间（防止误切换）、切换时需要按住的修饰键、按住鼠标按键时不切换。
- 默认开启 **切换时同步剪贴板**，双向，支持文字、富文本和图片（最大 100 MB，分块传输）。文件的复制粘贴暂不支持。
- **鼠标滚轮（在另一台 Mac 上）**：在服务端设置方向（与 Windows 一致 / 与 macOS 自然滚动一致）、平滑滚动和速度。另一台 Mac 上开着 Mos 也能正常工作。
- 为了安全，本机锁屏、睡眠、显示器睡眠、切换用户或连接中断时，控制权会自动回到本机。
- 如果有应用开启了“安全输入”（比如正在输入密码），键盘暂时无法共享，菜单里会有提示。

## 7. 其他功能的简单用法

- **防止锁屏**：在菜单里选“立即开启（无限期）”或“开启一段时间”。“自动计划”在工作日 08:00–19:00 自动开启，时段、每周的工作日、节假日数据和手动指定的日期都在设置页里调整。可以设置全局快捷键。
- **菜单栏图标**：按住 ⌘ 把要隐藏的图标拖到「<」**左侧**（或在设置页里把 App 设为“始终隐藏”），点「<」显示或隐藏，按住 ⌥ 点击显示全部，右键点击打开菜单。OneSwitch 自己的图标永远不会被隐藏。隐藏期间 macOS 会禁用通知中心；默认开启的“点击时钟时临时显示全部并打开通知中心”会替你处理，关掉通知中心后自动恢复隐藏。
- **系统监控**：在设置页里勾选要显示的指标，可以选择显示样式（文字、图标+数值、迷你图）、刷新间隔，也可以把几个指标合并成一个图标显示。

## 8. 故障排查

| 现象 | 处理方法 |
| --- | --- |
| 菜单栏上找不到 OneSwitch 图标 | 图标可能被刘海挡住，或者被收进了系统的“«”里。先减少菜单栏上的图标数量。在“访达”里再次打开 OneSwitch.app，会直接弹出设置窗口。 |
| 提示“OneSwitch 已在运行” | 同一时间只能运行一份。已经在运行的那份会弹出设置窗口；如果没有弹出，在“活动监视器”里结束 OneSwitch 进程后再打开。 |
| 雷雳互联一直显示“正在查找另一台 Mac” | 1）检查雷雳线；设置页“雷雳线”一项应显示已连接。2）两台 Mac 的配对码必须完全一致。3）“本地网络”权限是否已允许。4）在终端运行 `ping 10.77.0.2`（在笔记本上 ping 10.77.0.1）看是否能通。5）如果开了防火墙，在“系统设置 → 网络 → 防火墙 → 选项”里允许 OneSwitch 接收传入连接。6）点“重新连接”，或在“诊断”里点“拷贝诊断信息”查看详情。 |
| 显示“配对码不匹配” | 两台 Mac 重新填写同一个配对码（区分大小写，注意前后不要有空格）。 |
| 显示“未获得本地网络权限” | 系统设置 → 隐私与安全性 → 本地网络 → 打开 OneSwitch，然后重新启动 OneSwitch。 |
| 键鼠共享不起作用，或权限已授权却仍提示没有权限 | 在“辅助功能”和“输入监控”列表里选中 OneSwitch，点“−”删除，再点“+”重新添加 `/Applications/OneSwitch.app`，然后重启 OneSwitch。出现这种情况，多半是之前装过不同签名的版本。 |
| 每次更新后权限都失效 | 说明构建机没有运行过 `scripts/setup-signing.sh`，用的是 ad-hoc 签名。运行它，重新安装，最后授权一次。 |
| 开机没有自动启动 | 设置 → 通用 → 启动，看状态一栏；如果显示需要允许，就去“系统设置 → 通用 → 登录项”里打开 OneSwitch。 |
| 同步文件夹显示“文件夹不存在或已被移动” | 接上外接磁盘，或把文件夹移回原位置。确认位置正确后，点“重新创建标记…”。 |
| `deploy-peer.sh` 找不到对方 | 确认对方开了“远程登录”，并且公钥已经加进对方的 `~/.ssh/authorized_keys`。也可以用 `PEER=用户名@IP` 直接指定地址。 |
| 想让雷雳网桥恢复原来的自动获取地址 | 设置 → 雷雳互联 → 恢复为自动（DHCP）。 |

## 9. 日志与数据位置

- **日志文件**：`~/Library/Logs/OneSwitch/OneSwitch.log`，超过 5 MB 会轮转成 `OneSwitch.log.1`。“设置 → 通用 → 日志”里可以直接查看最近的日志、在访达中显示日志文件，也可以打开“详细日志（调试用）”。
- **系统日志**（实时查看）：

  ```sh
  log stream --predicate 'subsystem == "com.oneswitch.app"' --level debug
  ```

- **数据目录**：`~/Library/Application Support/OneSwitch/`（文件同步的索引在 `sync/` 下，还有节假日缓存等）。
- **设置项**：保存在 `com.oneswitch.app` 的偏好设置里，可以用 `defaults read com.oneswitch.app` 查看。
- **签名钥匙串**：`~/Library/Application Support/OneSwitch-Signing/`，只在构建机上有。里面有自签名证书，导入过开发者 ID 的话还有它的私钥——不要随手删除这个目录。

## 10. 卸载

1. 如果不想保留静态 IP，先在“设置 → 雷雳互联”点“恢复为自动（DHCP）”。
2. 从菜单栏退出 OneSwitch，删除 `/Applications/OneSwitch.app`，并在“系统设置 → 通用 → 登录项”中移除它。
3. 如果要清掉所有数据：删除 `~/Library/Application Support/OneSwitch/` 和 `~/Library/Logs/OneSwitch/`，再执行 `defaults delete com.oneswitch.app`。同步文件夹里的文件不受影响，可以顺手删掉其中的 `.oneswitch` 目录。
4. 在“隐私与安全性”的各个权限列表里删除 OneSwitch。

## 11. 开发者说明

- 构建：`swift build --product OneSwitch`。自检程序在 `Checks/` 下，例如 `swift build --product CoreCheck && .build/debug/CoreCheck`，退出码为 0 表示通过。
- 在一台 Mac 上同时运行两份（测试同步或连接时用）：`open -n /Applications/OneSwitch.app --args --profile B`。每个配置档的设置、数据和日志（`OneSwitch-B.log`）都是分开的。
- 更多约定见 `CLAUDE.md`，各功能的设计说明见 `docs/specs/`。
